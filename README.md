# 🌲 Magical Forest Adventure

> A small interactive choose-your-path adventure game built with HTML, CSS, and JavaScript.

## 🎮 Overview

Magical Forest Adventure is a browser-based interactive story where the player chooses between different paths and makes decisions that lead to different scenes.

The project was built as a simple exercise in **DOM manipulation, JavaScript objects, event handling, and basic responsive web styling**.

## ✨ Features

- Interactive branching story
- Multiple paths and choices
- Dynamic scene rendering
- Button-based navigation
- Responsive layout
- No external libraries required

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

Clone the repository and open `index.html` in a modern browser.

```bash
git clone https://github.com/Mohammed11Yusuf/The-Magical-Forest-Adventure-game.git
cd The-Magical-Forest-Adventure-game
```

Then open `index.html`.
